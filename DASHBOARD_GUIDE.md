## Overview

The Test Dashboard provides a beautiful, interactive web interface to visualize your API automation test results. It includes:

- **Real-time Metrics**: Total, passed, failed, skipped tests, pass rate, and duration
- **Interactive Charts**: Pie charts and bar charts using Chart.js
- **Detailed Test Table**: Complete breakdown of individual test results
- **Category Breakdown**: Tests grouped by markers (boundary, localization, etc.)
- **Responsive Design**: Works on desktop and mobile devices

---

## Features

### 📊 Visual Metrics

- **Total Tests**: Overall count of tests executed
- **Passed/Failed/Skipped**: Individual counts with color coding
- **Pass Rate**: Percentage of tests that passed
- **Duration**: Total execution time

### 📈 Interactive Charts

1. **Test Results Overview** (Pie Chart)
   - Visual breakdown of passed, failed, and skipped tests
   - Color-coded segments (green, red, orange)

2. **Test Categories** (Stacked Bar Chart)
   - Tests grouped by markers (boundary, localization, generate, file_operations, process)
   - Stacked view showing passed/failed/skipped per category

### 📋 Detailed Test Table

- Test names (cleaned for readability)
- Status badges (passed, failed, skipped)
- Individual test duration
- Sortable and scrollable

## Quick Start

### Method 1: Automated Script (Recommended)

```bash
# Run all tests and generate dashboard
./run_tests_with_dashboard.sh

# Run specific test group and generate dashboard
./run_tests_with_dashboard.sh boundary
./run_tests_with_dashboard.sh localization
```

This will:
1. Run tests with pytest
2. Generate JSON report
3. Create the dashboard automatically
4. Show you where the dashboard is located

### Method 2: Manual Steps

```bash
# Step 1: Install dependencies
pip install -r requirements.txt

# Step 2: Run tests with JSON report
pytest tests/ -v --json-report --json-report-file=.test_report.json

# Step 3: Generate dashboard
python3 generate_dashboard.py

# Step 4: Open dashboard
xdg-open reports/dashboard.html   # Linux
open reports/dashboard.html        # macOS
start reports/dashboard.html       # Windows
```

## Generating the Dashboard

### Prerequisites

1. **pytest-json-report** installed (included in requirements.txt)
2. Tests must be run with JSON reporting enabled

### Using the Dashboard Generator

The `generate_dashboard.py` script reads the JSON test report and generates an HTML dashboard.

**Script Location**: `generate_dashboard.py`

**Usage**:
```bash
python3 generate_dashboard.py
```

**Input**: `.test_report.json` (generated by pytest)
**Output**: `reports/dashboard.html`

**Example Output**:
```

============================================================

Loading test results from: .test_report.json
Calculating metrics...
Generating dashboard...
✅ Dashboard generated successfully: reports/dashboard.html

============================================================

  Total Tests: 15
  Passed: 14
  Failed: 0
  Skipped: 1
  Pass Rate: 93.3%
  Duration: 35.9s
============================================================

🎉 Open the dashboard: file:///home/user/API_Automation/reports/dashboard.html
```

### Test Command Options

**Run all tests with dashboard**:
```bash
pytest tests/ -v --json-report --json-report-file=.test_report.json
python3 generate_dashboard.py
```

**Run specific test group**:
```bash
pytest -m boundary -v --json-report --json-report-file=.test_report.json
python3 generate_dashboard.py
```

**Include other reports too**:
```bash
pytest tests/ -v \
    --html=reports/report.html --self-contained-html \
    --alluredir=allure-results \
    --json-report --json-report-file=.test_report.json
python3 generate_dashboard.py
```

- **Title**: "API Automation Test Dashboard"

## CI/CD Integration

The dashboard is automatically generated in GitHub Actions workflows.

### Workflow Configuration

The dashboard generation is included in `.github/workflows/api-tests.yml`:

```yaml
- name: Run tests
  run: |
    pytest tests/ -v \
      --json-report --json-report-file=.test_report.json \
      --html=reports/report.html --self-contained-html \
      --alluredir=allure-results

- name: Generate dashboard
  if: always()
  run: |
    python generate_dashboard.py

- name: Upload dashboard
  if: always()
  uses: actions/upload-artifact@v4
  with:
    name: test-dashboard-python-${{ matrix.python-version }}
    path: reports/dashboard.html
    retention-days: 30
```

### Accessing Dashboard in CI/CD

1. Go to **Actions** tab on GitHub
2. Click on a workflow run
3. Scroll to **Artifacts** section
4. Download **test-dashboard-python-X.XX**
5. Extract and open `dashboard.html` in browser

### Dashboard for Each Python Version

The CI/CD runs tests on multiple Python versions (3.10, 3.11, 3.12), generating a separate dashboard for each:

- `test-dashboard-python-3.10`
- `test-dashboard-python-3.11`
- `test-dashboard-python-3.12`

## Customization

### Modifying Colors

Edit `generate_dashboard.py` and update the color schemes:

```python
# Pie chart colors
backgroundColor: ['#10b981', '#ef4444', '#f59e0b'],

# Bar chart colors
datasets: [
    { label: 'Passed', backgroundColor: '#10b981' },
    { label: 'Failed', backgroundColor: '#ef4444' },
    { label: 'Skipped', backgroundColor: '#f59e0b' }
]
```

### Adding More Charts

Add new chart sections in the HTML template within `generate_dashboard.py`:

```python
html += '''
<div class="chart-card">
    <h2>Your Custom Chart</h2>
    <canvas id="customChart"></canvas>
</div>
'''

# Add corresponding JavaScript Chart.js code
```

```python
def calculate_metrics(data):

    custom_metric = calculate_your_metric(data)

    return {
        # ...existing metrics
        'custom_metric': custom_metric
    }
```

## Troubleshooting

### Issue: "Test results file not found"

**Cause**: JSON report not generated

**Solution**:
```bash
# Make sure to run tests with JSON report flag
pytest tests/ --json-report --json-report-file=.test_report.json
```

### Issue: Dashboard is blank or has no data

**Cause**: No tests were run or JSON file is empty

**Solution**:
1. Check if `.test_report.json` exists
2. Check if it contains test data
3. Re-run tests to generate fresh data

### Issue: Charts not displaying

**Cause**: JavaScript not loading or Chart.js CDN issue

**Solution**:
1. Check internet connection (CDN required)
2. Open browser console for errors
3. Try different browser

### Issue: "Module not found: pytest-json-report"

**Cause**: Missing dependency

**Solution**:
```bash
pip install pytest-json-report
# Or
pip install -r requirements.txt
```

### Issue: Wrong test counts

**Cause**: Stale JSON report from previous run

**Solution**:
```bash
# Remove old report
rm .test_report.json

# Run tests again
pytest tests/ --json-report --json-report-file=.test_report.json
python3 generate_dashboard.py
```

## Best Practices

1. **Generate Fresh Data**: Always run tests before generating dashboard
2. **Clean Reports**: Delete old `.test_report.json` before new test runs
3. **Save Historical Dashboards**: Rename and save dashboards with timestamps
   ```bash
   cp reports/dashboard.html reports/dashboard-$(date +%Y%m%d-%H%M%S).html
   ```
4. **Compare Runs**: Keep multiple dashboards to compare test trends
5. **Share Results**: Dashboard is self-contained HTML - easy to share via email/Slack

## FAQ

**Q: Can I customize the dashboard appearance?**
A: Yes! Edit the CSS in `generate_dashboard.py`. Look for the `<style>` section.

**Q: Does the dashboard work offline?**
A: Mostly yes, but Chart.js is loaded from CDN. For fully offline use, download Chart.js locally.

**Q: Can I add more charts?**
A: Yes! Add new canvas elements and Chart.js initialization in the HTML template.

**Q: How do I share the dashboard?**
A: The HTML file is self-contained. Just send the `dashboard.html` file - recipients can open it in any browser.

**Q: Can I integrate with other CI/CD systems?**
A: Yes! The dashboard generation is platform-agnostic. Just ensure pytest runs with `--json-report`.
